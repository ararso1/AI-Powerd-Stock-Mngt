# Csolve brand & UI tokens

Canonical tokens live in `stock-frontend/app/globals.css`.

| Token | Hex | Use |
|-------|-----|-----|
| `--csolve-espresso` | `#3C2415` | Sidebar, headings |
| `--csolve-roast` | `#6F4E37` | Primary actions |
| `--csolve-roast-hover` | `#5A3F2C` | Primary hover |
| `--csolve-bean` | `#8B5E3C` | Accents, charts |
| `--csolve-caramel` | `#C4A484` | Soft accents, active nav |
| `--csolve-cream` | `#F5F0E8` | App desk background |
| `--csolve-parchment` | `#FFFBF5` | Cards / surfaces |
| `--csolve-leaf` | `#4A7C59` | Success |
| `--csolve-cherry` | `#A63D2F` | Destructive / alerts |

Legacy `--frappe-*` variables alias to these tokens so existing desk components pick up the coffee theme without a mass rename.
